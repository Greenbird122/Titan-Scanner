## The Credibility Playbook

Read `guides/credibility_guide.md` for the full strategy. The short version:

1. **Live proof** — Every finding has a curl command they can run
2. **Verification scripts** — Python code that hits live servers
3. **Honest correction** — False positives are admitted, not hidden
4. **Exploit tools** — Working PoCs, not just markdown
5. **Testimonials** — Real people saying real things

The #1 response to "you just used AI": **"Run the curl command. If I'm wrong, you owe me nothing."**
